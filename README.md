# 🥗 Dieta Iao - Aplicación de Control Nutricional y Seguimiento

Sistema completo de seguimiento nutricional, cálculo de equivalencias alimentarias y registro diario integrado con **AppSheet** y **Google Sheets**.

## 📂 Estructura del Repositorio

- `index.html`: Interfaz web interactiva construida con **Tailwind CSS** y **Vue 3** optimizada para dispositivos móviles y de escritorio.
- `data/`: Contiene las tablas estructuradas en CSV exportadas desde Google Sheets:
  - `Diario.csv`: Historial y registro diario de tomas, peso y porcentajes de cumplimiento.
  - `Opciones_Predefinidas.csv`: Opciones predefinidas para Comidas, Snacks y Cenas.
  - `Base_de_Datos.csv`: Catálogo completo de alimentos clasificados por categorías (Hidratos, Proteínas, Grasas, Frutas, Verduras).

## 🚀 Despliegue en GitHub Pages

1. Sube todos los archivos de este repositorio a tu rama principal (`main`).
2. Ve a los ajustes (**Settings**) de tu repositorio en GitHub.
3. Entra en la sección **Pages** (en el menú lateral izquierdo).
4. En **Build and deployment**, selecciona la rama `main` y la carpeta `/ (root)`.
5. ¡Listo! Tu aplicación estará accesible online.
